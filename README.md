Coin de Para
🌿 Présentation du projet

Coin de Para est un site web dédié à la parapharmacie, développé par la startup NextLine pour l’entreprise Coin de Para.
Ce projet vise à offrir aux visiteurs une expérience simple, moderne et intuitive pour découvrir différentes catégories de produits, consulter les détails de chaque produit, details et formulaire et les question.

🎯 Objectifs

Créer un site web moderne et facile à utiliser.

Mettre en valeur la qualité des produits de Coin de Para.

Assurer une navigation fluide et responsive sur tous les écrans (desktop, tablette, mobile).

Développer le projet selon les bonnes pratiques web et les standards W3C.

🛠 Instructions pour travailler sur le projet

Travailler sur la branche develop pour les nouvelles fonctionnalités.

Créer des branches spécifiques pour chaque feature ou amélioration.

Exemple : homepage, produit, faq,categorie.

Soumettre vos modifications via pull requests pour validation avant de fusionner dans develop.

Publier la version finale sur GitHub Pages ou Vercel.

[2023] Développeur web et web mobile

📝 Contexte

La startup NextLine a été choisie par Coin de Para pour développer un site web qui :

Aide les visiteurs à découvrir différentes catégories de produits.

Permet de consulter les détails de chaque produit.

Fournit des conseils pour la santé et le bien-être.

L’objectif est de créer un site simple, moderne et attrayant, démontrant la qualité des produits.

👥 User Stories
Conception

En tant que concepteur, je vais dessiner la structure Zoning des pages : Accueil, Catégories, Produits, Détails Produit, FAQ.

Je vais créer des Wireframes pour montrer l’organisation des pages.

Je vais réaliser les Maquettes pour desktop et mobile.

Je vais créer un Prototype interactif du site.

Je vais ajouter sur la page Home une galerie d’images des produits les plus vendus.

Développement Front-End

Transformer les maquettes en pages web fonctionnelles avec HTML et CSS.

Ajouter une fonction de pagination sur la page produits (4 produits par page).

Créer un formulaire dans la section FAQ avec validation via pattern.

Garantir que le site soit responsive et esthétique sur tous les écrans.

Suivre les standards web et valider le code via W3C.

Publier le site sur GitHub Pages ou Vercel.
